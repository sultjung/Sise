# 시세 데이터 운영 기준

각 표본은 확인일, 원문 URL, 단지명, 매매 총액(IQD), 면적(m²), 매물 유형(아파트·매매)을 모두 보유해야 한다. 링크가 삭제되었거나 가격 또는 면적이 빠진 게시물은 가격 산정과 지역 순위에서 제외한다.

`complex-history.json`에는 월말에 확정된 값만 `verified_month_end` 상태로 저장한다. 월중 값은 `interim_unverified`이며 비교표와 추세 그래프에 사용하지 않는다. 과거 스냅샷은 수정하지 않고, 후속 링크 상태는 별도 검증 기록으로 관리한다.

비스마야는 공식 분양가와 민간 재판매 호가를 분리하며, 민간 표본에서는 양도권, 미납잔금, 분할납부, 보증인 변경 광고를 제외한다.
